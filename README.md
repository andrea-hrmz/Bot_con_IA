# Bot_con_IA

Este bot para discord funciona simplemente para identificar qué personaje de sanrio se está viendo con solo una imagen, algo rápido para identificar en medio de una conversación.
Los personajes que puede reconocer son:

Kirimichan
Hangyodon
Tuxedosam
Cogimyun
Marroncream
Usahana
Goropikadon
Wish me mell
Dear Daniel
Coro-chan
Mimmy

Simplemente se debe de añadir el comando '$check' en el mensaje con una foto del personaje a reconocer, también se le dará un dato curioso de el personaje al usuario.
